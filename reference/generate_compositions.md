# Generate all compositions of n into k parts

This is a helper function for
[`find_p_multi_mv()`](https://bowers-illinois-edu.github.io/DrBristol/reference/find_p_multi_mv.md)

## Usage

``` r
generate_compositions(n, k)
```

## Arguments

- n:

  Integer to partition

- k:

  Number of parts

## Value

Matrix where each row is a k-way composition of n
